## Projects

**Career-wave** — [repo](https://github.com/kushGupta-15/career-wave)
Full-stack job portal built with Next.js and TypeScript, supporting job posting, search, saving, and applications. Relational PostgreSQL schema designed with Prisma, business logic implemented through Next.js Server Actions. Google/GitHub OAuth via NextAuth with role-based workflows for companies and job seekers. Stripe-powered paid job postings with webhook activation, Inngest-driven expiration scheduling, UploadThing uploads, and Resend notifications.
`Next.js` `TypeScript` `Prisma` `PostgreSQL` `NextAuth` `Stripe` `Inngest`

**SketchBattle** — [repo](https://github.com/kushGupta-15/sketchbattle)
Real-time multiplayer drawing and guessing game, inspired by Skribbl.io. React 18/TypeScript frontend with a Node.js/Express backend, synchronized in real time through Socket.IO on an interactive HTML5 Canvas. Features timed rounds, dynamic rank-based scoring, password-protected rooms, progressive word hints, and reconnection handling, alongside peer-to-peer video chat and JWT authentication across both REST and Socket.IO connections.
`React` `TypeScript` `Node.js` `Express` `Socket.IO` `MongoDB`

**Streamify** — [repo](https://github.com/kushGupta-15/streamify)
Full-stack language exchange platform connecting users globally. RESTful APIs with JWT-based authentication handle onboarding, profile updates, and session management, backed by a friend-request system with pending/accepted states in MongoDB. Integrated Stream Chat and Video SDKs for real-time conversations and live video practice sessions, with a responsive, theme-enabled UI built in Tailwind CSS and DaisyUI.
`React` `JavaScript` `Stream Chat` `Stream Video` `Node.js` `MongoDB`
